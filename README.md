A Minecraft mod, curseforge page: https://www.curseforge.com/minecraft/mc-mods/bloomeries

Adds bloomeries made from bricks or mud bricks (so 2 variants in total). Used for better but slower smelting outputs.
Video showcase of how to build the bloomeries. (doesnt show the UI or the smelting process): https://www.youtube.com/watch?v=99dhrWW1zn4

Coded with 0 prior knowledge of Java or Minecraft modding, but had a lot of experience with C# which helped a lot.
